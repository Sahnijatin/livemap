# LiveMap Delivery Roadmap

Spec: `docs/superpowers/specs/2026-10-14-livemap-design.md` (section 16 defines the phases).

The spec covers six subsystems. Each gets its own plan, written when the previous phase has landed, so it can reference the real interfaces that phase produced. Each phase ships working, testable software.

| # | Plan | Delivers | Depends on |
|---|---|---|---|
| 1 | `2026-10-14-01-engine.md` | Watcher, tree-sitter analyzers (structure + imports), project model, differ, local server with token auth, CLI, first UI (tree + inspector, live updates) | – |
| 2 | Agents (written after 1) | Hook script, `livemap init`, Claude Code / Codex / Cursor adapters, git pull mode, attribution, flags and pause, Activity feed | 1 |
| 3 | Domain views (written after 2) | Routes, schema, deps, env analyzers; Schema, API, Stack views | 1 |
| 4 | Full UI (written after 3) | Map with React Flow + ELK, folder/file/function zoom, motion system matching `docs/design/prototype.html`, ⌘K, responsive layouts | 1, 3 |
| 5 | History and sharing (written after 4) | Event store, timeline scrubber, snapshot export, AI summaries | 1, 2 |
| 6 | Packaging (written after 5) | npm publish as `livemap`, README, docs, demo replay | all |

Name: `livemap` is unclaimed on npm (checked 2026-10-14) and is the product name.
