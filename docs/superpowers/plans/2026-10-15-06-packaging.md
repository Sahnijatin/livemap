# Phase 6: Packaging and Launch Prep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make LiveMap installable from an npm tarball, shrink the export page, hold the first-load budget, close the open follow-up issues and add CI.

**Architecture:** No new subsystems. Grammars for the export page move from the bundle into JSON files that `livemap export` injects per project. The tree-sitter grammars LiveMap uses are copied into `dist/grammars/` so the package stops depending on `tree-sitter-wasms`. Everything else is a local fix with its own test.

**Tech Stack:** TypeScript ESM (tsup, vitest), React 18 + Vite 5 + Zustand + React Flow, Shiki 1.29 (`shiki/core`), web-tree-sitter 0.25, Playwright, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-10-14-livemap-design.md (section 11 packaging, section 12 privacy). Scope comes from the phase 6 brief, quoted in the ledger below where it decides something.

## Global Constraints

- Node 18+ (`engines.node >=18`, tsup `target: 'node18'`). No native modules.
- Never `npm publish`, never push to main, never merge, never make the repo public.
- `.env` values are never stored, sent or logged.
- Copy (docs, UI text, commit messages): no em dashes, US spelling ("license", "canceled", "color"), concise and direct.
- Every commit message ends with `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Never commit `.superpowers/`.
- UI changes: screenshots in light and dark at 1440 and 390 px wide, looked at before the task is done. Match docs/design/prototype.html (bright, Apple-like).
- First-load budget: main JS chunk at most 82.29 kB gzip (Vite's reported figure).
- README screenshots under 400 KB each, no real machine paths.

## Review Focus

1. **Export with no highlightable code** (`--no-code`, or only `.txt`/unknown languages): the page must load and show code views as plain text with no grammar, no wasm and no console error. Test in Task 6.
2. **Old history and old exports after the `agentEvents` batch message lands:** history files hold single `agentEvent` messages, and replay must still apply them. Test in Task 9.
3. **Tarball install into a path with a space, run by `npx`-style bin shim:** `livemap --help`, `init`, a short start and hook resolution must work. Test in Task 7's smoke script (temp dir name contains a space).
4. **`--pull` followed by an all-digit folder:** `livemap --pull ./30` must still mean "pull every 15 s in folder ./30". Test in Task 1.
5. **Prisma relation using a mapped column** (`fields: [userId]` with `userId String @map("user_id")` and a SQL migration): one `user_id` row, still marked FK. Test in Task 2.

## Ruling ledger

Each ruling: what was decided, and the cost if wrong.

| # | Ruling | Cost if wrong |
|---|---|---|
| R1 | #42 (docs sync after #40) stays a separate PR; this branch starts from main. | A trivial merge if both touch docs/guide.md. |
| R2 | `--pull N` with a space accepts N when it is all digits; a folder named only with digits must be written `./30`. | Someone with an all-digit folder name gets "invalid --pull interval" and has to add `./`. |
| R3 | Map folder labels are lifted above edges by giving folder nodes a header label node with `zIndex: 1`, not by rerouting edges. | Edges still cross folder bodies (only the label is protected). |
| R4 | #17b (sync snapshot JSON.stringify): measure at 5,000 files; move off the flush path with `setImmediate` only if over 50 ms; no worker thread. | A stall up to 50 ms every 500 events on huge projects. |
| R5 | Export keeps the Oniguruma wasm (injected only when code is embedded) instead of switching to Shiki's JS regex engine. | About 230 kB gzip that the JS engine would have saved. |
| R6 | Copy the 15 used tree-sitter grammars into `dist/grammars/` and drop the `tree-sitter-wasms` dependency. | Tarball grows by the 15 grammars (about 27 MB raw, less packed); installs shrink by about 23 MB. Re-sync needed when grammars change. |
| R7 | #8 (launch link by script), #7 (watcher startup), #9 counters and `deferRelink`, #6 change history and example names: closed as accepted with a comment, no code. | Rare double-redeem warning; about 5% slower watcher start. |

| R9 | First-load budget is enforced by `scripts/check-budget.mjs` in CI, reading Vite's build manifest and gzipping the entry chunk with zlib level 9. | A few hundred bytes of difference from Vite's printed figure. |
| R10 | CI runs on Node 20 on ubuntu-latest only. Perf tests (`test:perf`) stay out of CI. | A Node 18-only or Windows break is not caught in CI. |
| R11 | README Quickstart switches to `npx livemap` with a note that it works once published; "from source" moves to CONTRIBUTING. | Readers before publish hit a 404 from npm. |
